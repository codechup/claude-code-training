The installation itself cannot be captured honestly on a machine that is
already installed, and re-installing per OS was out of reach for this session:
the lesson therefore shows the install commands as `<CodeBlock>`s copied
character-for-character from `https://code.claude.com/docs/en/setup.md` and
records only the verification step as a transcript.

## Post-processing

Only stdout was captured; the command line was prepended by hand as a `› ` line
(the prompt glyph `src/components/mdx/transcript.ts` parses), byte-identical to
what was typed. The `#` provenance first line is not part of the recording, so
the lesson embeds these files with `<Transcript range="2-…">`.
