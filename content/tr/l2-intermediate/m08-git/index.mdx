Bu modül Claude Code'u git iş akışınıza dahil eder: doğru trailer'larla (kuyruk bilgisi) conventional commit yazmak, ajanların izole çalışabilmesi için worktree'ler ve branch'ler (dallar) arasında çalışmak, gerçek kanıt ekli pull request'ler açmak ve bir insana kalmadan sorunları yakalayan inceleme komutlarını çalıştırmak. Modül, GitHub uygulamasının üstüne ne kattığıyla biter.

1. `01-commits-and-conventions` — Conventional commit'ler, co-author trailer'ları, Claude ne zaman commit atar (15 min, core).
2. `02-worktrees-branches` — `/branch`, `EnterWorktree`, `isolation: worktree`, paralel branch'ler (20 min, core).
3. `03-pull-requests` — Kanıtlı `gh` pull request'leri, PR şablonları, inceleme yorumları (20 min, core).
4. `04-code-review-commands` — `/code-review` seviyeleri, `/simplify`, `/security-review`, `/diff` (20 min, core).
5. `05-github-app` — `/install-github-app` ve neyi mümkün kıldığı (10 min, advanced).
