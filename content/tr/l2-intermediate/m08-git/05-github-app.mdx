## Özet

Bu ders `/install-github-app` komutunun ne yaptığını anlatır: Claude GitHub App’i kurar, bir kimlik doğrulama secret’ı ayarlar (API key için `ANTHROPIC_API_KEY`, abonelik token’ı için `CLAUDE_CODE_OAUTH_TOKEN`), workflow dosyalarını içeren bir branch push eder ve tarayıcınızda oluşturulmaya hazır bir pull request açar. `@claude` ancak siz o PR’ı merge ettikten sonra çalışır. Ders, uygulamanın on bir izinlik ortak setini ve Claude Code GitHub Action’ın bunlardan yalnızca üçüne (Contents, Issues, Pull requests) dayandığını, hızlı kurulum ile manuel kurulum arasındaki seçimi, aynı adı paylaşan üç ürünü (GitHub Actions, yönetilen Code Review, web’de Claude Code) ve temiz kaldırma adımlarını kapsar. Bu derste lab repo etiketi yoktur: komut gerçek bir GitHub deposunu değiştirir.
