Bu modül Claude Code'u etkileşimli terminalin dışına çıkarır. `claude -p` ile yapılandırılmış çıktı kullanarak etkileşimsiz (headless) çalıştıracak, otomatik PR incelemesi ve issue-to-PR (konudan pull request'e) otomasyonu için GitHub Actions'a bağlayacak, GitLab ve kurumsal sunucu eşdeğerlerine bakacak ve Agent SDK üzerinde hem TypeScript hem Python'da özel bir ajan kuracaksınız.

1. `01-claude-p` — `--output-format json|stream-json`, `--json-schema`, `--allowedTools`, `--permission-mode`, `--permission-prompts none` ile `claude -p`, çıkış kodları (20 min, core).
2. `02-github-actions-review` — Lab: `anthropics/claude-code-action@v1` ile PR incelemesi (25 min, core).
3. `03-issue-to-pr` — Lab: `@claude` ile issue → PR otomasyonu (25 min, core).
4. `04-gitlab-and-others` — GitLab CI/CD, kurumsal sunucu notları (10 min, advanced).
5. `05-agent-sdk-typescript` — Lab: `@anthropic-ai/claude-agent-sdk` ile özel bir ajan (30 min, advanced).
6. `06-agent-sdk-python` — Lab: aynı ajanın Python karşılığı (25 min, advanced).
