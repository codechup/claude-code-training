Bu modül Claude Code'u etkileşimli terminalin dışına çıkarır. `claude -p` ile yapılandırılmış çıktı kullanarak etkileşimsiz (headless) çalıştıracak, otomatik PR incelemesi ve issue-to-PR (konudan pull request'e) otomasyonu için GitHub Actions'a bağlayacak, GitLab ve kurumsal sunucu eşdeğerlerine bakacak ve Agent SDK üzerinde hem TypeScript hem Python'da özel bir agent kuracaksınız.
