Bu ders GitHub’ın remote [MCP server](/tr/playbook/glossary/#mcp-server)’ını — Claude Code'a dış araçlar ve veri kaynakları sunan program — dokümanların gösterdiği şekilde ekler ve üç uzak server durumunu — `✔ Connected`, `! Needs authentication`, `✘ Failed to connect` — ayırt etmeyi öğretir. Laboratuvar hiçbir gerçek hesapta kimlik doğrulaması yapmaz: geçersiz bir token ile server eklenir ve `claude mcp get` çıktısındaki gerçek hata detayı okunur.
