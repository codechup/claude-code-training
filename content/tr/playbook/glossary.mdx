Bu sayfa dersler çevrildikçe adım adım oluşturulur.

## Terimler

### agentic loop

Claude Code’un bir görevi tamamlarken döndüğü çevrim: bağlam toplar, bir tool ile eylem alır, sonucu doğrular ve gerekirse tekrar eder.

### agent

Bir hedefi kendi başına adım adım yürüten, araç (tool) çağırabilen yapay zekâ süreci; Claude Code’un kendisi bir agent’tır.

### tool

Claude’un dosya okuma, düzenleme, komut çalıştırma gibi işleri yapmak için çağırdığı yerleşik araç (Read, Edit, Bash, Grep …).

### prompt

Claude’a verdiğiniz istek metni; iyi bir prompt hedefi, kısıtları ve kanıt beklentisini söyler.

### MCP server

Model Context Protocol ile Claude’a dış araç ve veri sağlayan sunucu (GitHub, veritabanı, tarayıcı …).

### subagent

Ana oturumun bir alt görevi devrettiği, kendi bağlam penceresi ve araç izinleri olan yardımcı agent.

### effort

Modelin bir yanıt için harcadığı düşünme çabası seviyesi (`/effort low…max`); kalite ile hız/maliyet arasındaki kaldıraç.

### transcript

Gerçek bir Claude Code oturumunun kaydı; bu sitede yalnızca gerçekten çalıştırılmış oturumlar gösterilir.

### headless

Etkileşimli arayüz olmadan tek komutla çalıştırma (`claude -p`); betiklerden ve CI’dan kullanım için.

### plan mode

Claude’un değişiklik yapmadan önce yalnızca okuyup bir plan sunduğu mod (Shift+Tab ile geçilir).

### hook

Claude Code’un yaşam döngüsündeki belirli anlarda (ör. bir tool çağrısından önce) otomatik çalışan komut.

### skill

`SKILL.md` ile tanımlanan, `/ad` ile çağrılan ya da Claude’un kendisinin yüklediği yeniden kullanılabilir talimat paketi.

### argument

Bir skill ya da komut çağrılırken sonuna eklenen, gövdede `$ARGUMENTS` ya da adlandırılmış `$name` yer tutucularıyla kullanılan değer.

### plugin

Claude Code’a hook, skill, subagent ve MCP server gibi bileşenleri paket hâlinde ekleyen, kurulup etkinleştirilebilen eklenti.

### matcher

Bir hook’un hangi tool ya da event üzerinde ateşleneceğini daraltan, tam ad listesi ya da düzenli ifade olarak değerlendirilebilen alan.

### hook event

Claude Code’un yaşam döngüsünde bir hook’un bağlanabildiği belirli an, ör. bir tool çağrısından önce ya da bir oturum başlarken.

### exit code

Bir komutun ya da hook betiğinin bitirdiğinde döndürdüğü sayı; Claude Code bunu 0 (başarı), 2 (engelleme) ve diğer her şey (çoğu event’ta engellemeyen hata) olarak yorumlar.

### debug log

`--debug-file` ya da `/debug` ile açılan, hook’ların ve diğer arka plan işlemlerinin tam çıktısının yazıldığı, transcript’te görünmeyen günlük dosyası.

### sandbox

Bir sürecin dosya sistemi ve ağ erişimini işletim sistemi düzeyinde kısıtlayan izole çalışma ortamı.

### permission mode

Bir oturumun tool çağrılarını nasıl onaylayacağını belirleyen kip (`default`, `plan`, `acceptEdits`, `bypassPermissions` …).

### workflow

Claude Code’un bir görev için planladığı ve yürüttüğü, birden çok adımdan oluşan otomatik iş akışı.

### checkpoint

Claude Code’un bir oturum sırasında dosya durumunu kaydettiği, `/rewind` ile geri dönülebilen an.

### fork

Bir oturumu, konuşma geçmişinin bir kopyasında ya da izole bir bağlamda devam ettirmek (`/fork`, `/branch`).

### token

Bir dil modelinin metni işlerken kullandığı en küçük birim; maliyet ve context window token cinsinden ölçülür.

### context window

Bir modelin tek bir istekte görebildiği toplam token miktarı; aşıldığında en eski içerik düşer ya da sıkıştırılır.

### commit

Bir git deposundaki değişiklik kümesinin kalıcı, mesajlı kaydı.

### branch

Bir git deposunun bağımsız bir geliştirme hattı; değişiklikler ana koddan ayrı, kendi commit zincirinde birikir.

### worktree

Aynı deponun farklı bir branch’ini ayrı bir dizinde çalışır durumda tutan ek bir git çalışma ağacı.

### merge

İki git branch’inin tarihçesini birleştirme işlemi; bu sitede pull request’ler squash-merge ile birleştirilir.

### diff

Bir dosyadaki ya da commit’teki değişikliklerin satır satır gösterimi (`git diff`).

### pull request

Bir branch’teki değişikliklerin gözden geçirilip ana koda alınması için açılan istek.

### issue

Bir GitHub deposundaki takip edilen görev ya da hata kaydı.

### GitHub App

Claude Code’u bir GitHub deposuna bağlayan, pull request’lerde ve issue’larda otomatik olarak çalışan entegrasyon.

### CI

Sürekli entegrasyon: her push’ta ya da pull request’te otomatik olarak testleri ve kontrolleri çalıştıran hat.

### secret

Bir webhook URL’si ya da API anahtarı gibi, depoya commit’lenmemesi gereken hassas değer.

### checklist

Bir laboratuvarın ya da görevin tamamlandığını doğrulamak için sırayla işaretlenen madde listesi.
