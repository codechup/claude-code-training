## Özet

Bu ders Claude Code’da oturum açmayı anlatır: Claude Pro/Max aboneliği, Claude for Teams veya Enterprise, Claude Console (v2.1.242’den itibaren API anahtarı oluşturmadan da) ve Amazon Bedrock, Google Cloud’s Agent Platform, Microsoft Foundry gibi bulut sağlayıcıları. Tarayıcı akışının ayrıntılarını (`c` ile URL kopyalama, `Paste code here if prompted` istemi, `Login successful` mesajı), CI için `claude setup-token` ile üretilen bir yıllık OAuth token’ı ve yedi basamaklı kimlik bilgisi önceliğini kapsar — ortamda duran bir `ANTHROPIC_API_KEY`, onaylandıktan sonra aboneliğinizin önüne geçer ve faturayı Console kuruluşunuza yazar. Laboratuvar, `claude auth status --text` ve `claude auth status` çıktılarıyla hangi kimlik bilgisinin etkin olduğunu kanıtlar.
