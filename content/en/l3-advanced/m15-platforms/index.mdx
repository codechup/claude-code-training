This module is a tour of every place Claude Code runs: the VS Code and JetBrains extensions, the desktop app with its scheduled tasks, the web and cloud sessions at claude.ai/code, Remote Control and the mobile app, Claude in Chrome for driving a browser, Claude Tag in Slack, and running several sessions side by side in a terminal multiplexer.

1. `01-vs-code` — The VS Code extension: inline chat, diff view, selection context (15 min, core).
2. `02-jetbrains` — JetBrains plugin (10 min, core).
3. `03-desktop-app` — Desktop app: scheduled tasks, iOS simulator pane, browser launching (15 min, core).
4. `04-web-and-cloud-sessions` — claude.ai/code, cloud environments, `--teleport`, ultrareview (15 min, core).
5. `05-remote-control-mobile` — Remote Control and the mobile app (10 min, core).
6. `06-chrome` — Claude in Chrome: navigation, forms, screenshots, console (15 min, core).
7. `07-slack-claude-tag` — Claude Tag in Slack: setup, connections, scheduled jobs (10 min, advanced).
8. `08-tmux-multi-session` — Terminal multiplexers and several sessions side by side (10 min, advanced).
