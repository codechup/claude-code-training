This module delegates work to subagents — separate agents with their own tools, model, and permissions, launched from inside a session. You will meet the built-in agents, learn the frontmatter that defines a custom one, build a small set of them for real tasks, control which model each one runs on, and use fork, background, and worktree isolation for agents that should not share your main session's state.
