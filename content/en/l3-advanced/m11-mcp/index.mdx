This module connects Claude Code to systems outside your codebase through the Model Context Protocol: external tools, resources, and data sources exposed over HTTP, stdio, or WebSocket. You will add and manage servers at different scopes, work through labs against GitHub, a browser, and a database, write a minimal server of your own, and finish with the trust and supply-chain questions MCP raises.
