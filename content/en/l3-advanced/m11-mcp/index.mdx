This module connects Claude Code to systems outside your codebase through the Model Context Protocol: external tools, resources, and data sources exposed over HTTP, stdio, or WebSocket. You will add and manage servers at different scopes, work through labs against GitHub, a browser, and a database, write a minimal server of your own, and finish with the trust and supply-chain questions MCP raises.

1. `01-mcp-concepts` — Servers, tools, resources; transports (HTTP, stdio, WebSocket; SSE deprecated) (15 min, core).
2. `02-add-list-remove-scopes` — `claude mcp add/list/remove`, `--scope`, `.mcp.json`, `${VAR:-default}`, OAuth sign-in (20 min, core).
3. `03-github-mcp` — Lab: issues and PRs through the GitHub MCP server (20 min, core).
4. `04-browser-mcp` — Lab: Playwright/Chrome for UI checks (20 min, core).
5. `05-database-mcp` — Lab: SQLite/Postgres schema discovery and queries (20 min, core).
6. `06-write-your-own-server` — Lab: a minimal MCP server with the TypeScript SDK (30 min, advanced).
7. `07-mcp-security` — Trust, supply chain, managed MCP, least privilege (15 min, advanced).
