This module takes Claude Code out of the interactive terminal. You will run it non-interactively with `claude -p` and structured output, wire it into GitHub Actions for automated PR review and issue-to-PR automation, look at GitLab and enterprise-server equivalents, and build a custom agent on top of the Agent SDK in both TypeScript and Python.
