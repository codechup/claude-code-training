This module takes Claude Code out of the interactive terminal. You will run it non-interactively with `claude -p` and structured output, wire it into GitHub Actions for automated PR review and issue-to-PR automation, look at GitLab and enterprise-server equivalents, and build a custom agent on top of the Agent SDK in both TypeScript and Python.

1. `01-claude-p` — `claude -p` with `--output-format json|stream-json`, `--json-schema`, `--allowedTools`, `--permission-mode`, `--permission-prompts none`, exit codes (20 min, core).
2. `02-github-actions-review` — Lab: `anthropics/claude-code-action@v1` PR review (25 min, core).
3. `03-issue-to-pr` — Lab: an issue → PR automation with `@claude` (25 min, core).
4. `04-gitlab-and-others` — GitLab CI/CD, enterprise server notes (10 min, advanced).
5. `05-agent-sdk-typescript` — Lab: a custom agent with `@anthropic-ai/claude-agent-sdk` (30 min, advanced).
6. `06-agent-sdk-python` — Lab: the same agent in Python (25 min, advanced).
