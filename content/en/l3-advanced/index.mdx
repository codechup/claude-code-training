Level 3 is about scaling what one session can do. You will delegate parts of a task to subagents with their own tools and models, connect Claude Code to external systems through MCP servers, and package skills and hooks as plugins other people can install.

It also takes Claude Code out of the interactive terminal: running headless in CI, driving GitHub Actions and issue-to-PR automation, building custom agents with the Agent SDK, and doing all of that securely — understanding the sandbox, prompt injection, and secret handling — on whichever platform you actually work on.

Prerequisite: Levels 1–2. Subagents, MCP servers, and CI automation all assume you already know how permissions, models, and hooks behave in a single interactive session.

- **Subagents and custom agents** (`m10-subagents`) — Delegate work to subagents with their own tools, model, and permissions.
- **Model Context Protocol** (`m11-mcp`) — Connect Claude Code to external tools and data through MCP servers.
- **Plugins and marketplaces** (`m12-plugins`) — Package skills, hooks, and agents as an installable plugin.
- **Headless, CI and the Agent SDK** (`m13-headless-ci`) — Run Claude Code non-interactively, in CI, and via the Agent SDK.
- **Working securely** (`m14-security`) — Sandboxing, prompt injection, secrets, and data retention.
- **Every place Claude Code runs** (`m15-platforms`) — VS Code, JetBrains, desktop, web, mobile, Chrome, Slack, and the terminal.
