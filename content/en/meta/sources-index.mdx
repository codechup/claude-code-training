Every factual claim on this site traces to a source, and every source is registered in one file:
[`content/_shared/sources.json`](https://github.com/codechup/claude-code-training/blob/main/content/_shared/sources.json).
This page is that registry, rendered — a single place to find the links without reading the
lessons around them.

## How to read it

**142 unique sources**, cited 254 times across 23 modules and sections. The counts differ because
a source that several modules rely on — the CLI reference, the settings page, the hooks
documentation — is listed under each of them.

By type: 121 official, 19 repositories, 2 articles. That balance is the project's source policy
(D041–D044) showing through. Official documentation comes first and is mandatory in every lesson's
sources block; Anthropic's own writing comes next; a community source is cited only when an
official page also confirms the claim.

The **verified** date is the day someone actually opened the page and confirmed it still supported
the claim it is cited for — not the day the link was added and not the day the page was last
edited by its author. Dates are refreshed by the
[`/verify-sources`](https://github.com/codechup/claude-code-training/blob/main/.claude/skills/verify-sources/SKILL.md)
skill before a release, and a weekly
[link sweep](https://github.com/codechup/claude-code-training/blob/main/.github/workflows/links-weekly.yml)
opens an issue when a URL stops resolving. A date that has aged is a signal to check the page
yourself: Claude Code changes quickly, and a source that was accurate in September may describe a
flag that has since been renamed.

Documentation URLs ending in `.md` are the plain-text form of the official docs — the same page a
browser shows, in the form Claude Code fetches.
