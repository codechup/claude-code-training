This module is a tour of the terminal itself: the full built-in slash-command table, the CLI flags that change how a session starts, the commands for resuming and branching past sessions, and the keybindings, statusline, and theme settings that make the interface yours. It ends with the subcommands — `claude mcp`, `claude plugin` — and the environment variables worth knowing.

1. [`01-slash-command-reference`](/en/l1-beginner/m04-commands/slash-command-reference/) — The full built-in slash command table with one-line meanings (20 min, core).
2. [`02-cli-flags`](/en/l1-beginner/m04-commands/cli-flags/) — `claude`, `-p`, `-c`/`-r`, `--model`, `--effort`, `--permission-mode`, `--settings`, `--add-dir` (15 min, core).
3. [`03-sessions`](/en/l1-beginner/m04-commands/sessions/) — `/resume`, `/branch`, `/fork`, `--teleport`; naming and finding past sessions (15 min, core).
4. [`04-keybindings-statusline-theme`](/en/l1-beginner/m04-commands/keybindings-statusline-theme/) — Keyboard shortcuts, `/keybindings`, `/statusline`, `/theme`, `/tui fullscreen`, output styles (15 min, core).
5. [`05-subcommands`](/en/l1-beginner/m04-commands/subcommands/) — `claude mcp`, `claude plugin`, `/config`, environment variables that matter (15 min, core).
