This module is a tour of the terminal itself: the full built-in slash-command table, the CLI flags that change how a session starts, the commands for resuming and branching past sessions, and the keybindings, statusline, and theme settings that make the interface yours. It ends with the subcommands — `claude mcp`, `claude plugin`, `claude config` — and the environment variables worth knowing.

1. `01-slash-command-reference` — The full built-in slash command table with one-line meanings (20 min, core).
2. `02-cli-flags` — `claude`, `-p`, `-c`/`-r`, `--model`, `--effort`, `--permission-mode`, `--settings`, `--add-dir` (15 min, core).
3. `03-sessions` — `/resume`, `/branch`, `/fork`, `--teleport`; naming and finding past sessions (15 min, core).
4. `04-keybindings-statusline-theme` — Keyboard shortcuts, `/keybindings`, `/statusline`, `/theme`, `/fullscreen`, output styles (15 min, core).
5. `05-subcommands` — `claude mcp`, `claude plugin`, `claude config`, environment variables that matter (15 min, core).
