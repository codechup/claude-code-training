This module teaches Claude Code to remember what matters about your project instead of re-explaining it every session. You will write a project `CLAUDE.md`, understand how memory sources at different scopes combine, add path-scoped rules for specific areas of a codebase, and use auto-memory and the memory commands to keep what is remembered accurate and current.
