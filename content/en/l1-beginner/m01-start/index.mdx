This module gets Claude Code onto your machine and into your hands. You will see what it actually is and how its agent loop reads, edits, and runs code before installing it on macOS, Linux, or Windows, signing in, and running a first real session in a lab repository. It ends with the maintenance habits — `claude doctor`, `claude update`, release channels — that keep the install healthy afterwards.

1. [`01-what-claude-code-is`](/en/l1-beginner/m01-start/what-claude-code-is/) — Explain what Claude Code is, how the agent loop reads/edits/runs, and where it runs (CLI, IDE, desktop, web) (10 min, intro).
2. [`02-install`](/en/l1-beginner/m01-start/install/) — Install with the native installer, Homebrew, WinGet or npm on macOS/Linux/Windows; verify with `claude --version` (15 min, intro).
3. [`03-authenticate`](/en/l1-beginner/m01-start/authenticate/) — Sign in with a subscription, an API key or `claude setup-token`; understand keyless Console sign-in and profiles (10 min, intro).
4. [`04-first-session`](/en/l1-beginner/m01-start/first-session/) — Run a first session in the lab repo: ask, read, edit, run tests; read the TUI (10 min, core).
5. [`05-doctor-update-channels`](/en/l1-beginner/m01-start/doctor-update-channels/) — Keep the install healthy: `claude doctor`, `claude update`, release channels, `--version` (10 min, core).
