This module gets Claude Code onto your machine and into your hands. You will see what it actually is and how its agent loop reads, edits, and runs code before installing it on macOS, Linux, or Windows, signing in, and running a first real session in a lab repository. It ends with the maintenance habits — `claude doctor`, `claude update`, release channels — that keep the install healthy afterwards.
