This module is where you learn to actually work with Claude Code inside a project: writing a task it can act on, understanding the built-in tools it reaches for, and controlling what it is allowed to do through permission modes and plan mode. It closes with checkpoints and the context window — how to undo safely and see what the agent is holding in mind.
