By the end of Level 1 you are installed, authenticated, and working with Claude Code with confidence: you understand permissions, memory, and the built-in commands well enough to use them without second-guessing what a keystroke or a flag will do.

This level starts from zero. It covers getting the tool running on your machine, holding a real conversation with it inside a project, teaching it what it needs to remember about your codebase, and finding your way around the terminal interface and its built-in commands.

There is no prerequisite beyond a terminal and a willingness to try things in a scratch repository. Everything after Level 2 assumes the habits built here — reading a plan before approving it, knowing what a permission mode does, and keeping a useful `CLAUDE.md`.

- **Getting Claude Code running** (`m01-start`) — Install Claude Code, sign in, and run your first session.
- **Talking to Claude Code** (`m02-interact`) — Prompt well, use the built-in tools, and control permissions and plan mode.
- **Giving Claude memory** (`m03-memory`) — Write CLAUDE.md and rules so Claude remembers what matters about your project.
- **Built-in commands and the terminal** (`m04-commands`) — The full slash-command table, CLI flags, sessions, and the terminal UI.
