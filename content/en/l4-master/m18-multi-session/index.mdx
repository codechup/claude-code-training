This module coordinates several parallel sessions on shared work — the way this course's own plans were written. You will learn the structure of a plan file, the generated `STATE.md` and its claim protocol, disjoint `owned_paths` and per-plan worktrees, assigning model and effort hints by work type, writing a hand-off another session can actually resume from, and finish by walking this repository's own `plans/` directory as a worked example.

1. `01-plan-files` — Plan files with frontmatter, ten sections, milestones (20 min, core).
2. `02-state-md-and-claims` — A generated STATE.md, the claim protocol, stale claims (20 min, core).
3. `03-owned-paths-worktrees` — Disjoint `owned_paths`, worktrees per plan, shared-file rules (20 min, core).
4. `04-model-effort-hints` — Assigning `model_hint`/`effort_hint` by work type (10 min, core).
5. `05-handoff-notes` — Writing hand-offs another session can resume from; blocked and open questions (15 min, core).
6. `06-this-repo-as-example` — Walk through this site's own `plans/` and STATE.md (15 min, advanced).
