Level 4 is for running Claude Code at the scale of a team or a system rather than a single session. You will orchestrate several agents on one task with the Workflow tool, let work continue unattended with autonomous loops and routines, and coordinate multiple parallel sessions on shared work using plan files and a generated `STATE.md` — the same mechanism this repository's own plans use.

It finishes with shipping visual output — artifacts, the design canvas, browser automation — and the organisational side: rolling Claude Code out to a team, budgeting cost, and keeping large codebases and infrastructure workable.

Prerequisite: Levels 1–3. Orchestration, autonomy, and multi-session coordination all build directly on subagents, hooks, and CI automation from Level 3.

- **Multi-agent orchestration** (`m16-orchestration`) — Coordinate several agents on one task with the Workflow tool.
- **Autonomous loops** (`m17-autonomy`) — Let Claude Code keep working unattended, on a schedule or a loop.
- **Coordinating parallel sessions** (`m18-multi-session`) — Plan files, STATE.md, and disjoint ownership across parallel sessions.
- **Artifacts, design and browsers** (`m19-visual`) — Publish artifacts, use the design canvas, and automate a browser.
- **Team adoption** (`m20-team`) — Shared settings, managed policy, cost budgeting, and rollout.
- **Large codebases and infrastructure** (`m21-scale`) — Work in large codebases and configure caching, gateways, and devcontainers.
