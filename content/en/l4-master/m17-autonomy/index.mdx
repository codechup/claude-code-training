---
title: 'Autonomous loops'
description: 'Let Claude Code keep working unattended, on a schedule or a loop.'
order: 17
---

This module lets Claude Code keep working without someone watching every step: `/loop` on a fixed or self-paced interval, routines triggered by cron, an API endpoint, or a GitHub event, `/goal` for stop-hook-driven objectives, scheduled tasks in the desktop app, and the monitors and channels that keep autonomous work observable rather than opaque.
