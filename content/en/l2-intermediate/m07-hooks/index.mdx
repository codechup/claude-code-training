This module gives Claude Code a way to react to its own actions programmatically. You will learn the anatomy of a hook — events, matchers, the stdin/stdout JSON contract, and exit codes — then build hooks that block a dangerous command, format a file after it is edited, send a notification when a session ends, and load project state when one starts, before working through the full event catalogue and how to debug a hook that isn't firing.

1. `01-hook-anatomy` — Events, matchers, stdin/stdout JSON, exit codes 0/2/other, `hookSpecificOutput` (20 min, core).
2. `02-block-dangerous-commands` — Lab: PreToolUse guard for `rm -rf` / force-push with `permissionDecision: deny` (20 min, core).
3. `03-format-on-save` — Lab: PostToolUse formatter (Prettier/gofmt) (15 min, core).
4. `04-notify-when-done` — Lab: Notification/Stop → desktop and Slack notification (15 min, core).
5. `05-session-start-context` — Lab: SessionStart loads STATE.md; Stop runs the test suite (20 min, core).
6. `06-event-catalogue` — All 32 events grouped (lifecycle, prompt, tools, agents/tasks, elicitation) with a use for each (20 min, advanced).
7. `07-debugging-hooks` — `/hooks`, logs, common failures, hook precedence across scopes (15 min, advanced).
