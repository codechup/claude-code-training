title: 'Prompting for agents'
description: 'Decompose tasks, state constraints, and avoid common prompting mistakes.'
order: 9
---

This module is about the instructions you give an agent, independent of any specific tool. You will learn to decompose a task into verifiable steps, state constraints and acceptance criteria up front, run review-and-refine loops without drifting from the original goal, and recognise the ten prompting anti-patterns that cause the most wasted sessions.
