title: 'Skills and custom commands'
description: 'Package repeated instructions as skills and custom commands.'
order: 6
---

This module packages the instructions you find yourself repeating into skills — the single mechanism behind both custom commands and reusable agent behaviour. You will learn the frontmatter that defines a skill, how arguments reach it, and build a purely prompt-based skill and a skill that runs a script, before measuring whether the skills you have are actually being used.
