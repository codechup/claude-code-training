This module packages the instructions you find yourself repeating into skills — the single mechanism behind both custom commands and reusable agent behaviour. You will learn the frontmatter that defines a skill, how arguments reach it, and build a purely prompt-based skill and a skill that runs a script, before measuring whether the skills you have are actually being used.

1. `01-skills-vs-commands` — Skills as the single mechanism; where they live (user, project, plugin, nested) (15 min, core).
2. `02-skill-md-anatomy` — Frontmatter fields (`name`, `description`, `when_to_use`, `argument-hint`, `arguments`, `allowed-tools`, `disallowed-tools`, `model`, `effort`, `context`, `agent`, `background`, `hooks`, `paths`, `shell`) (20 min, core).
3. `03-arguments` — `$ARGUMENTS`, `$0`/`$1`, named arguments, `${CLAUDE_SKILL_DIR}` and friends; Lab: `/commit-msg` (20 min, core).
4. `04-prompt-only-skills` — Lab: `/review-security` checklist skill (15 min, core).
5. `05-tool-running-skills` — Lab: `/new-component` with a script, `allowed-tools`, `context: fork` (25 min, core).
6. `06-skill-doctor` — `/skill-doctor`: measuring whether skills are used, fixing descriptions (10 min, advanced).
