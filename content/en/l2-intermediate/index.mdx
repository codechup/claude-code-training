Level 2 turns Claude Code from a tool you operate into a tool you configure. You will choose a model and an effort level deliberately instead of leaving the defaults on, package your own repeated instructions as skills, and react to the agent's actions programmatically with hooks.

It closes with the git workflow that makes all of this useful in a team: commits, worktrees, and pull requests written and reviewed with Claude Code in the loop, plus the prompting discipline that keeps an agent on a well-scoped task instead of wandering.

Prerequisite: Level 1. You should already be comfortable with permission modes, plan mode, and a working `CLAUDE.md` before choosing models by cost and reliability, or writing a hook that can block a dangerous command.

- **Choosing model and effort** (`m05-models-effort`) — Pick a model and an effort level on purpose, and watch cost and usage.
- **Skills and custom commands** (`m06-skills`) — Package repeated instructions as skills and custom commands.
- **Hooks** (`m07-hooks`) — React to the agent's actions programmatically, at every lifecycle event.
- **Git workflows with Claude** (`m08-git`) — Commits, worktrees, and pull requests with Claude Code in the loop.
- **Prompting for agents** (`m09-prompting`) — Decompose tasks, state constraints, and avoid common prompting mistakes.
