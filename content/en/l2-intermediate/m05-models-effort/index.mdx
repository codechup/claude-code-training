---
title: 'Choosing model and effort'
description: 'Pick a model and an effort level on purpose, and watch cost and usage.'
order: 5
---

This module replaces the default model and effort level with a deliberate choice. You will learn what each model in the family is good at, run the same task on three of them to compare output and cost, and control how hard the agent thinks with effort levels and fast mode. It ends with the cost and usage commands that make deliberate choice possible in the first place, and a note on Mythos-class models.
