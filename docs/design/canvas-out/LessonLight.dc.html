Block dangerous commands with a PreToolUse hook

20 min core hookssecurity updated 2026-09-06 · verified v2.1.263
You willWrite a hook that inspects every Bash call before it runs, exits with code 2 to block, and returns a JSON reason Claude can read.
When not to use thisA permission deny rule in settings.json is simpler when you only need to block a fixed command pattern. Reach for a hook when the decision depends on arguments or repository state.
macOS / LinuxWindows
.claude/hooks/guard-bash.mjs copy
1 const input = JSON.parse(await readStdin()); 2 const cmd = input.tool_input?.command ?? ''; 3 if (/rm\s+-rf\s+(?!\/tmp)/.test(cmd)) { ← anything outside /tmp 4 console.log(JSON.stringify({ decision: 'block', reason: 'rm -rf outside /tmp' })); 5 process.exit(2); 6 }
